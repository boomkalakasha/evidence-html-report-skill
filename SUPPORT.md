# Support / 支持

If Codex does not list the Skill, check that `SKILL.md` is directly inside the installed `evidence-html-report/` directory and open a new session. If generation fails, run the bundled quick-start example first; then check the field named in the error against the [content model](references/content-model.md).

如果 Codex 找不到 Skill，确认 `SKILL.md` 直接位于安装后的 `evidence-html-report/` 下，再开一个新会话。生成失败时先运行随包样例，再按错误提示对照[内容模型](references/content-model.md)。

For other questions, use [GitHub Issues](https://github.com/boomkalakasha/evidence-html-report-skill/issues). Include the version, environment, steps, and a small fictional JSON if possible. Do not share private reports, credentials, or internal paths. For vulnerabilities, follow [SECURITY.md](SECURITY.md).

其他问题可在 [GitHub Issues](https://github.com/boomkalakasha/evidence-html-report-skill/issues) 提出，附版本、环境、复现步骤，能用小型虚构 JSON 最好。不要附私有报告、凭据或内部路径。漏洞请按[安全说明](SECURITY.md)报告。
