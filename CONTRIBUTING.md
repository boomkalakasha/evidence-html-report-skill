# Contributing / 贡献

Use a focused PR. Describe what changes for report authors or readers and how you checked it. Keep examples fictional and check the affected README paths in both languages. Run the [verification steps](README.md#repository-layout-and-verification) relevant to the change; use the browser checks for navigation, diagrams, or print behavior.

请用范围明确的 PR，说明作者或读者会看到什么变化、如何验证。示例使用虚构材料，两种语言中受影响的使用路径一起核对。运行相关[验证步骤](README.zh-CN.md#项目结构与验证)；改动目录、图解或打印时，加跑对应的浏览器检查。

By contributing, confirm that you can submit the material under the project’s [Apache License 2.0](LICENSE) and that it does not contain confidential or customer-specific material.

提交前请确认有权按本项目的 [Apache License 2.0](LICENSE) 提供材料，并移除保密内容及客户资料。
